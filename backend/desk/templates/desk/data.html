Формат JSON

{
  "version": 1,
  "records": [{
    "entity": "task",
    "source": "my_source",
    "external_id": "stable-id",
    "import_batch": "snapshot-date",
    "fields": {
      "title": "Следующий шаг",
      "status": "planned"
    }
  }]
}

Связи: объект с source и external_id соответствующей записи. Суммы — строки, например "1250.50". Даты — YYYY-MM-DD. В CSV — эти же поля колонками, с entity/source/external_id. Полное описание и команды SSH находятся в эксплуатационной инструкции.

Резервные копии

JSON содержит рабочие записи и метаданные документов, без файлов и ключей. Полная копия .desk содержит базу и зашифрованные вложения; ключ хранится отдельно. Полная закрытая копия SQLite дополнительно хранит историю и учётную запись. Резервирование и проверенное восстановление доступны через отдельную команду на сервере.

Скачанный файл содержит личные данные — храните его закрыто. Исторические накопленные оплаты не импортируются как сегодняшний приход.
