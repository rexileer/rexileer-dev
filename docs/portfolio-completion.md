# Завершение сайта по ревью

Работа выполнена от опубликованного `a1384b7`, с сохранением всей истории
`codex/services-portfolio`. Django, админка, существующие кейсы, RU/EN,
тёмный дизайн, лаймовый акцент и намеренные ссылки в footer сохранены.

## Содержание и предложение

- Проверены все 26 кейсов на RU/EN. У 11 проектов перечни экранов отделены от
  инженерных решений: опубликованы компактные списки подтверждённых возможностей,
  планы визуалов убраны. Остальные инженерные карточки имеют пояснения.
- Для карточек написаны законченные краткие задача/решение/результат.
  Автоматическое обрезание предложений удалено.
- Поля «Мой вклад» расширены до 512 символов; синхронизация больше не режет их
  на 160-м символе. Миграция `0006` также сохраняет целые поля AI-черновиков.
- Убраны служебные оценки, финансовые ремарки и повторное описание в начале кейса.
  Личные прототипы и расширенные версии явно обозначены.
- AI Leads: на VPS проверены `enqueue_due_sources`, `run_source_parser`, вызов
  адаптера и сохранение результатов. Обработка веб-источников реализована;
  обе языковые версии описывают Celery/Redis, расписания и историю запусков.
- Основные CTA объясняют, что прислать и как начинается обсуждение. Email доступен
  рядом с Telegram в hero и на страницах кейсов.
- Процесс описывает согласование этапов, стоимости, сроков, критериев приёмки,
  передачу кода/конфигурации/инструкций и отдельное согласование поддержки.
- Платный аудит имеет определённый результат: письменный разбор с причинами,
  рисками, сохраняемыми частями, приоритетами исправлений и планом оценки этапов.

## Публикация

- Актуальная история переносится в `main` обычным fast-forward без удаления истории.
- Production публикуется из `main`, автоматически после push или вручную через
  GitHub Actions → CI/CD → Run workflow с выбранной веткой `main`.
- Push рабочих веток запускает проверки. Deploy-job для них пропускается.
- Environment `main_deploy` допускает только ветку `main`. Это также блокирует
  публикацию из старых веток, сохранивших прежнюю версию workflow.
- Общая очередь `rexileer-production`, без отмены текущего деплоя.
- CI: Ruff, Django check, миграции, JavaScript syntax, static collection и все
  существующие Django tests. Серверные настройки и значения секретов сохранены.
