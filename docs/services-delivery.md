# Сайт услуг и кейсов — 5 октября 2026

## Результат

Сохранены Django, административная панель, реестр проектов и существующий
Docker/GitHub Actions deployment. Добавлены серверные HTML-страницы и небольшое
прогрессивное улучшение на JavaScript. Новый frontend-фреймворк не требуется.

- Главная: Python Backend / AI Integration Developer, четыре направления услуг,
  доработка существующих проектов, шесть избранных кейсов, процесс работы и Telegram.
- `/services/` и четыре посадочные страницы:
  `/services/python-backend/`, `/services/telegram-bots/`,
  `/services/parsers-automation/`, `/services/ai-rag/`.
- `/projects/` и `/work/`: тематические фильтры; все 26 опубликованных кейсов
  доступны по `/projects/<slug>/`.
- Полные английские страницы доступны с префиксом `/en/`. Переключатель сохраняет
  текущую страницу. Русский текст внутри настоящих скриншотов остаётся исходным.
- Уникальные метаданные, canonical, hreflang, Open Graph, JSON-LD, sitemap и
  настоящие 404. Текст, ссылки, FAQ и изображения доступны без JavaScript.
- События `telegram_click`, `email_click`, `case_open`: существующая админка,
  раздел Site events. Записываются только тип, размещение, путь, язык и время;
  query string и персональные данные в этот поток не передаются.
- Ссылка © на radiokp.ru и другая намеренная ссылка в footer сохранены.

## Изображения

Полностью проверены 168 PNG в предоставленной папке; 108 уникальны, 60 — точные
дубли. Использованы 44 исходника для десяти кейсов, подготовлены 132 WebP-версии.
Полные версии — lossless, варианты 640/960 px — без увеличения исходника.
Исходная папка сохранена. Галереи открывают полное разрешение.

Соответствие кейсов, использованные и пропущенные файлы, причины пропуска и
конкретные рекомендации для остальных проектов: [asset-audit.md](asset-audit.md).
Полная привязка каждого исходника к выходным файлам: [assets-manifest.json](assets-manifest.json).

Payment, Steps и MEXC содержат предоставленные иллюстрации диалогов по handlers,
а не реальные скриншоты чатов; на сайте это подписано. Случайные Unsplash-обложки
убраны. Для кейсов без материалов используется подтверждённый стек в техническом
placeholder. Для AI Media сохранён существующий SVG. Непроверенные детали
real-estate-parser не представлены как реализованные возможности.

## Проверка

- Ruff format/check, Django system check и проверка миграций: успешно.
- 16 Django tests: успешно.
- JavaScript syntax check и сборка Django static assets: успешно.
- Browser QA: 68 RU/EN страниц, 102 внутренних ссылки, 132 WebP-файла,
  40 сочетаний страницы/ширины (320, 390, 768, 1440 px), без горизонтального overflow.
- Проверены меню и Escape/focus, фильтры и сохранение категории, галерея и стрелки,
  FAQ, переключение языка, CTA и запись события с CSRF, режим без JavaScript.
- Проверены метаданные, JSON-LD, HTTP 404, оригинальные пасхалки; ошибок JavaScript нет.
- Визуально проверены desktop/mobile, настоящие кадры и подписи иллюстраций.
  Локальный замер без throttling: CLS главной ~0.021, проверенных посадочных 0;
  это лабораторный ориентир, а не замер скорости мобильной сети пользователей.

Отдельных TypeScript/npm build-команд в проекте нет. Сборку контейнера и
публикацию выполняет существующий CI/CD с environment `main_deploy`.
